# Arcify 新标签页（Spotlight）

Arcify 接管 Chrome 的新标签页（⌘T / Ctrl+T、新窗口、标签栏上的「+」）：页面中间只有一个输入框，像 Arc 的命令栏一样，输入关键词就按优先级搜索常用网址、历史记录和书签。

## 使用

页面上不显示按键提示，完整的快捷键列表在右下角齿轮 →「快捷键」中（⌘ 在 Windows / Linux 上显示为 Ctrl）。

| 操作 | 按键 |
| --- | --- |
| 选择结果 | ↑ ↓（Mac 也可用 Ctrl+N / Ctrl+P），或鼠标悬停 |
| 打开 | ↵ 或单击：在当前标签打开 |
| 在后台新标签打开 | ⌘↵ / Ctrl+↵，或 ⌘ / Ctrl+单击 |
| 直接用搜索引擎搜索 | ⇧↵（Shift+Enter），无论当前选中哪一行；⌘⇧↵ / Ctrl+Shift+↵ 在后台新标签搜索。快捷词范围内会加上 `site:域名` |
| 使用快捷词 | 输入 `/` 加快捷词，再按空格或 Tab |
| 退出快捷词 | 输入框为空时按 Backspace，或点击快捷词标签 |
| 清除 | Esc：先清空文字，再退出快捷词 |
| 关闭标签页 | 1.5 秒内连按两次 Esc（第一次清除，同时提示「再按一次 Esc 关闭标签页」），可在设置中关闭 |

- 输入框为空时列出最常用的网址；此时按 ↵ 不会打开任何页面，要先用 ↑↓ 选中。
- 输入像网址的内容（`example.com`、`localhost:3000`、IP）时，第一行是「打开」；否则第一行是「搜索」（Chrome 默认搜索引擎），除非有足够好的匹配（网址开头或标题词首命中），这时最佳结果排在第一行。
- 中文输入法组字过程中的回车和方向键交给输入法，不会误触发打开。

## 搜索与排序

三个来源按你指定的优先级排列：**常用网址 > 历史记录 > 书签**。同一来源内先比匹配度，再比使用情况。同一页面出现在多个来源时只显示一次，按最高的来源计。

**匹配度**（多个关键词时每个都必须命中）：

| 命中位置 | 分数 |
| --- | --- |
| 域名开头（`git` → github.com） | 1.0 |
| 域名某一段开头（`google` → mail.google.com） | 0.92 |
| 标题的词首；中文标题中包含 | 0.85 |
| 域名中包含 | 0.7 |
| 标题中包含 | 0.6 |
| 路径或参数中包含 | 0.5 |

**常用网址（带衰减的 LFU）**：每次从新标签页打开一个网址，它的分数加 1；分数每 14 天减半，所以既看次数，也让很久不用的网址逐渐让位。记录最多 500 条，满了淘汰分数最低的。还没积累到足够记录时，用 Chrome 自带的「最常访问」网站补位。只统计从新标签页打开的网址（不统计站内搜索结果页），设置中可一键清除。

历史记录按访问次数（手动输入的访问加倍）和最近访问时间排序，书签按最近使用时间排序。

## 打开时的加载反馈

按下 ↵、⇧↵ 或单击之后立刻进入「正在打开」状态，一直持续到目标网页开始加载、替换掉新标签页为止：

- 搜索框顶部出现一条来回流动的细进度条（不表示具体进度），被选中的行右侧出现转圈，其他行变淡；用 ⇧↵ 搜索时，列表会滚到「搜索」行并在那里转圈。
- 这期间输入、方向键、回车都不再响应，避免重复打开；Esc 只取消这个提示，无法撤回已经发出的跳转。
- 出错时提示会消失并显示原因；如果 15 秒后页面仍没有离开（例如链接是下载文件，或服务器没有返回页面），提示自动消失；从目标网页后退回到新标签页时不会残留。
- 在后台新标签页打开（⌘↵ / ⌘⇧↵）不进入这个状态，只显示一条提示。

同时缩短了按下回车到开始跳转的时间：后台先发起跳转，再记录「常用网址」（之前是先读写一次存储再跳转）；页面打开和开始输入时会提前唤醒 Arcify 的后台进程（Chrome 会让空闲约 30 秒的后台进程休眠，冷启动会额外增加延迟）。

## 连按 Esc 关闭

类似 ⌘Q 的「再按一次退出」：第一次 Esc 照常清空输入（或退出快捷词），底部提示「再按一次 Esc 关闭标签页」，提示条上的进度在 1.5 秒内走完；这段时间内再按一次 Esc 关闭当前标签页。两次之间输入、粘贴、选词或按其他键都会取消，需要重新按两次。设置 →「其他」中可以关闭这个功能（`newtabEscapeClose`）。

## 背景图片

设置 →「背景图片」：点击预览框或「选择图片」，也可以把图片拖进预览框。

- 图片会按屏幕分辨率缩小（最长边不超过 4K，绝不放大）并转成 WebP，几 MB 的照片通常只占几百 KB；动图只保留第一帧。
- 「淡化」用当前主题背景色盖在图片上（0–80%），浅色和深色主题下文字都清晰；「模糊」0–30px。搜索框和设置按钮会变成半透明毛玻璃。
- 图片保存在扩展的 IndexedDB 中，设置保存在 `chrome.storage.local` 的 `newtabWallpaper`。另外把一张 32px 的缩略图缓存在 localStorage，新标签页在 `<head>` 中（`wallpaper-boot.js`）同步读取它并模糊铺满，第一帧就有背景，完整图片解码后再淡入，不会先闪一下纯色背景。
- 「移除背景」恢复主题背景色。

## 性能

输入时不等待任何查询，每个按键都直接用内存中的数据算出结果，所以列表始终和输入内容一致，回车也总是作用于当前看到的结果。

- **内存索引**：常用网址、全部书签（`bookmarks.getTree` 一次读入，书签变化时自动重载）和最近 90 天的历史记录（最多 3000 条）在页面打开后加载，不阻塞首帧和焦点。网址解析结果会缓存，并在空闲时预先解析。
- **补充查询**：更早的历史记录仍用 `chrome.history.search` 查询，但只在停止输入约 120ms 后发出，同一时刻最多一个，期间的输入只保留最新一次，查过的词不再重复查。结果到达后合并进列表，用户已用方向键选中的行保持选中。
- **中文输入法**：组字过程中不搜索，选词完成后再搜索。
- **渲染**：内容没变的行直接复用（包括网站图标），不重建、不重新请求图标。

以模拟数据测试（历史 3000 条、书签 1500 条、常用 500 条，模拟每次历史查询 120ms 且依次执行，每 80ms 输入一个字符，共 18 个字符）：最近的历史结果在最后一个按键时立即出现（之前约 1.4 秒）；超过 90 天的历史结果约 0.25 秒后出现；后台查询从 36 次降到 2 次；每个按键的主线程耗时平均约 4ms，最慢约 15–19ms。

## 快捷词

输入 `/git` 再按空格（或 Tab），输入框前会出现「/git GitHub」标签，之后的关键词只在 github.com（含子域名）的常用网址、历史记录和书签中搜索。

- 只输入快捷词不加关键词时，第一行是「打开 GitHub」首页。
- 配置了站内搜索地址时，会多一行「在 GitHub 中搜索…」；没有配置时用 `site:域名 关键词` 交给默认搜索引擎。
- 默认提供 `/git`（GitHub）、`/yt`（YouTube）、`/mdn`（MDN）。

点击页面右下角的齿轮管理快捷词：

| 字段 | 说明 |
| --- | --- |
| 快捷词 | 小写字母、数字、`-`、`_`，最长 16 个字符，不能重复 |
| 名称 | 显示在标签上，留空则使用第一个域名 |
| 网站域名 | 一个或多个，逗号分隔；会自动去掉 `https://`、`www.`、路径，并包含子域名 |
| 站内搜索地址 | 可选，必须以 `http(s)://` 开头并包含 `%s`，例如 `https://github.com/search?q=%s` |

快捷词保存在 `chrome.storage.local` 的 `newtabShortcuts`。

## 输入框焦点

这是这类插件最难的部分。Chrome 打开新标签页时会把键盘焦点放在地址栏，而通过 `chrome_url_overrides` 替换的新标签页**无法自己把焦点拿回来**，`input.focus()` 没有可见效果，这是 Chrome 有意为之，没有官方 API 可以改变。

Arcify 的做法：

1. **自跳转**（`src/newtab/focus-boot.js`）：替换的新标签页在 `<head>` 中、任何渲染之前，用 `location.replace` 把自己换成同一页面加一个标记参数。经过一次跳转的页面可以获得焦点，`autofocus` 和 `input.focus()` 随之生效。`replace` 不产生历史记录（后退不会回到第一次的页面），标记参数随后用 `history.replaceState` 去掉，跳转前页面保持隐藏，不会闪出半成品。
2. **保底**（`src/newtab/newtab.js`）：页面获得焦点、标签页从后台切到前台、后退回到缓存的页面时都重新聚焦输入框；焦点意外落在页面空白处时，按下的字符会转进输入框；点击空白处也会回到输入框。打开设置弹窗时不会抢焦点。

已知限制：

- 地址栏会显示扩展页面的地址（`chrome-extension://…/newtab.html`），而不是空白。这是自跳转的代价。
- 按下 ⌘T 后在几十毫秒内立刻打字，开头的字符可能还留在地址栏里，并且 Chrome 不会打断正在地址栏输入的内容，这时会继续用地址栏。
- 第一次替换新标签页时，Chrome 会询问是否保留这项更改，请选择保留。
- 无痕窗口默认不启用扩展，仍是 Chrome 原生新标签页。

- [ ] 普通窗口按 ⌘T / Ctrl+T

## 代码位置

| 路径 | 内容 |
| --- | --- |
| `src/newtab/newtab.html / .css / .js` | 页面、样式、交互 |
| `src/newtab/focus-boot.js` | 焦点自跳转（同步，最先执行） |
| `src/newtab/search.js` | 纯函数：快捷词解析与校验、匹配、LFU、排序、结果行（页面与后台共用） |
| `src/newtab/escape-guard.js` | 连按两次 Esc 的判定 |
| `src/newtab/wallpaper.js`、`wallpaper-boot.js` | 背景图片的处理、存储与首帧显示 |
| `src/newtab/remote-query.js` | 历史记录补充查询的调度（防抖、单个在途、去重） |
| `src/background/newtab.js` | 后台：记录常用网址、在当前或后台标签打开、默认搜索引擎搜索 |
| `tests/newtab/` | 单元测试 |
