# Arcify 侧边栏

Arcify 的两大能力之一（另一个是 [Spotlight 新标签页](newtab.md)）：把 Arc 浏览器的侧边栏体验带到 Chrome 原生侧边面板（Side Panel）——固定页面（Pin）、文件夹、顶部图标区、竖排标签、原生分屏和 Peek 链接浮窗。

最低 Chrome 116；分屏需要 Chrome 155+。所有数据只保存在本机。

## 安装

见仓库根目录 [README](../README.md#getting-started)。侧边栏是 Arcify 插件的一部分，点击工具栏中的 Arcify 图标或按快捷键（Mac `⌘B`，其他平台 `Alt+B`）打开。

## 功能

### Pin（固定页面）

- 把 Tabs 区的标签拖到 Pin 区即可固定。关闭页面后入口仍保留，点击重新打开。
- 支持 HTTP/HTTPS、`chrome://`、本地文件等可重新打开的页面。浏览器重启后入口保留，但已恢复的标签不会自动重新绑定。
- 编辑按钮（或右键「重命名」）只修改展示名称，不改变 URL 和真实标签标题。
- 关闭按钮：页面已打开时关闭页面，已关闭时移除这个 Pin。拖回 Tabs 区则解除固定。
- 页面离开固定地址（子页面、查询参数或锚点变化）时，图标右上角显示琥珀色「↗」，悬停可查看当前地址和固定地址；返回固定地址或关闭标签后消失。
- 已打开的 Pin 会按 Pin 顺序排在真实标签栏前部（Chrome 原生固定标签之后），新建的普通标签不会插入其中；浮窗和分屏中的标签不参与排序。

### 文件夹与排序

- Pin 标题旁的按钮新建文件夹，文件夹右侧的加号新建子文件夹；点击文件夹展开或收起。
- Pin 与文件夹可以在同一层混合排序：
  - 拖到 Pin 行的上／下半区：插到该项之前／之后；
  - 拖到文件夹标题的上／下边缘：插到文件夹之前／之后；拖到中间区域：放入文件夹末尾；
  - 拖到展开文件夹的底部边缘：放到该文件夹最后；拖到 Pin 区空白处：移回顶层。
- 插入位置以高亮指示线为准，拖动时不显示文字提示或额外占位。
- 删除文件夹时，其中的 Pin 和子文件夹提升到上一层，不会删除内容。

### 顶部图标区

- Pin 上方只显示网站图标的区域，最多 8 个、两行，每行最多 4 个并等分宽度。可拖入普通标签或已有 Pin，拖到卡片左右两侧调整顺序。
- 点击行为与普通 Pin 相同。需要改名或删除时先拖回 Pin 区，拖到 Tabs 区则解除固定。
- 图标区为空时，拖到侧栏内容顶部边缘可放入第一个图标。

### Tabs（竖排标签）

- 显示当前窗口中未固定的标签，可拖拽排序（拖到行的上／下边缘）。
- 标题旁的「Clear」关闭当前窗口中非激活的普通标签，保留 Pin、Chrome 原生固定标签和当前分屏的另一侧。

### 分屏（Chrome 155+）

- 把一个标签拖到另一个标签行的**中间区域**，行内出现虚线半框预览，松手即组成 Chrome 原生分屏；落在左半边时拖动的标签在左侧，右半边在右侧。
- 插件会自动把两个标签挪到相邻位置并加入同一标签组。目标已在分屏中时不能拖入；被拖的标签若原本在分屏中，会先自动取消。
- 分屏中的两个标签在侧栏中显示为相连的一组并带分屏图标。
- 右键菜单：「取消分屏」「与当前标签页分屏」、重命名、关闭（支持方向键和 Esc）。
- 低于 Chrome 155 时不显示分屏区域，拖动行为与普通排序一致。

### Peek 链接浮窗（实验功能）

在设置 → 实验功能中开启，需要授予 HTTP/HTTPS 网站访问权限。

- Pin 页面中前台打开的新链接会直接在独立浮窗中打开，Pin 页面本身不跳转；后台标签（⌘/Ctrl+点击、中键）和网站自己的弹窗保持原样。
- 拦截方式：
  - 普通 `target="_blank"` 链接由内容脚本在点击时接管；
  - 网站用 `window.open(url)` 打开的新标签，由运行在页面主环境的脚本在 Chrome 创建标签**之前**接管，地址栏和标签栏不会闪动；
  - 只接管有用户手势、不带窗口尺寸参数的 http/https 请求，带 `width`/`height` 的网站弹窗（如登录授权）保持原样；
  - 网站先打开空白窗口再设置地址等少数情况，由后台把新标签移入浮窗，可能有极短的闪动。
- 浮窗尺寸按浏览器窗口宽、高的比例设置（默认 80% × 85%，居中），有紧凑／标准／宽大三个预设。
- 关闭功能后，页面脚本会被注销，不再加载到任何网页中。

#### 浮窗地址栏

浮窗顶部有一个紧凑的工具条：后退、刷新、当前地址（点击可编辑）、复制链接、回到标签页。

- 页面打开时完整显示约 2 秒，之后收起为域名小标签；鼠标移上、获得焦点或按快捷键时展开。
- 编辑地址后回车打开：像网址的内容（`example.com`、`localhost:3000`、IP）直接访问，其他文字用 Chrome 默认搜索引擎搜索；Esc 取消。
- 只出现在 http/https 页面；`chrome://` 页面、PDF、浏览器错误页无法注入，可用 Chrome 自带的后退快捷键返回。网页全屏时自动隐藏。

| 操作 | Mac | Windows / Linux |
| --- | --- | --- |
| 编辑地址 | ⌘L | Ctrl+L / Alt+D / F6 |
| 后退 / 前进 | ⌘[ ⌘]（不在输入框时也可用 ⌘← ⌘→） | Alt+← / Alt+→ |
| 刷新 | ⌘R | Ctrl+R / F5 |
| 复制链接 | ⌘⇧L | Ctrl+Shift+L |
| 回到标签页 | ⌘⇧O | Ctrl+Shift+O |

快捷键只在浮窗中生效，网页自己处理了的按键优先。复制链接同时注册为 Chrome 扩展命令，可在 `chrome://extensions/shortcuts` 修改。

### 外观与设置

- **外观**：主题模式（跟随系统／浅色／深色）、7 种预设背景色和 8 种强调色，也可用取色器自定义。预设背景各有浅色和深色版本；自定义背景时界面明暗由背景亮度自动决定。外观在页面首次绘制前从缓存应用，不会闪烁。
- **文字**：调整侧栏字体大小（11–18px）。
- **快捷键**：显示 Chrome 实际分配的「切换侧边栏」快捷键，「配置快捷键」打开 Chrome 的扩展快捷键页面；显示「未绑定」时请手动分配。
- **Pin 备份**：「保存备份」下载 JSON 文件；「恢复备份」合并恢复 Pin、文件夹层级、展开状态和图标区（超过 8 个的项目保留为普通 Pin），不恢复运行中的标签绑定。相同文件夹路径下的相同 URL 不会重复添加。

配色无法保证与 Chrome 自定义主题完全一致。拖动侧边面板与网页之间的分隔线可调整宽度。

### 图标与列表缓存

- 网站图标从 Chrome 本地的网站图标库读取（`favicon` 权限，不访问网络），缩成 32px 后缓存在扩展的 localStorage 中（最多 400 个，一周后自动刷新）；网页图标变化（如未读数）时自动更新。
- 侧栏重新打开时，先用上次的列表和缓存图标立即画出，再与后台的最新状态对齐，不会出现列表空白或图标闪烁。
- Chrome 没有记录图标的页面（如从备份恢复、尚未访问过的 Pin）仍直接加载网站自己的图标。

## 代码位置

| 路径 | 内容 |
| --- | --- |
| `src/background/sidebar.js` | 后台：Pin 数据、标签排序、分屏、Peek 浮窗 |
| `src/sidebar/` | 侧边栏界面（`sidepanel.html / .css / .js`） |
| `src/content/peek-content.js` | 链接拦截 + 浮窗地址栏（网页隔离环境，仅开启 Peek 时注册） |
| `src/content/peek-main.js` | 接管 `window.open`（网页主环境） |
| `src/shared/` | 与新标签页共用的主题、网站图标缓存 |
| `tests/sidebar/` | 单元测试 |

权限说明见根目录 [README](../README.md#permissions)。

### 手动测试 Peek

```bash
cd test-pages
python3 -m http.server 8000
```

打开 `http://localhost:8000/peek-test.html`，把它加入 Pin，在设置中开启「Pin 链接浮窗」，按页面上的说明逐项测试（前台／后台链接、`window.open`、网站弹窗、当前标签内跳转）。

### 数据存储

| 位置 | 内容 |
| --- | --- |
| `chrome.storage.local` | `pins`、`folders`、`fontSize`、`appearance`、`peekEnabled`、`peekSize` |
| `chrome.storage.session` | Pin 与真实标签的绑定、浮窗窗口、会话 ID（浏览器重启后清空） |
| 扩展页面 `localStorage` | 外观缓存、网站图标缓存、上次的列表快照 |

卸载扩展会删除以上全部数据。备份文件格式为 `{ "format": "Sidebar", "version": 1, ... }`，为兼容旧备份保持不变。
