新标签页设置

    背景图片

    图片只保存在本机，会自动压缩到适合屏幕的大小；动图只保留第一帧。

    快捷词

    输入 / 加快捷词再按空格（或 Tab），之后的关键词只在对应网站的常用网址、历史记录和书签中搜索。

      新增快捷词

      快捷键

      ↑↓或 ⌃N⌃P
      选择结果
      ↵
      打开选中的结果
      ⌘↵
      在后台新标签页打开（也可 ⌘+单击）
      ⇧↵
      不管选中哪一行，直接用默认搜索引擎搜索输入的文字；在快捷词范围内只搜该网站
      ⌘⇧↵
      在后台新标签页用搜索引擎搜索
      / 快捷词 空格 或 Tab
      进入快捷词范围，例如 /git react
      ⌫
      输入框为空时退出快捷词
      Esc
      清除输入或退出快捷词；1.5 秒内连按两次关闭标签页

      其他
